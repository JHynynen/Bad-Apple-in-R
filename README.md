# Bad-Apple-in-R
Bad Apple!! displayed in R using only the basic plots

I've only tested with Python 3.14 and latest versions of dependencies as of 04.10.2026\
Requires R, Python, as well as PyAV, Pandas, numpy, and scikit-images

Get the data from any old Bad Apple!! video (I really don't know if anything other than the provided will work)\
Get the required commands from the command generator and paste them into the base script\
I recommend running the line that gets the data from the file first, might take a while\
Also remember to change the directory to where the data file is in properly in R
